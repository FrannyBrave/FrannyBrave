## 📁 Portfolio Case Studies

### 🏥 [Splunk SIEM Implementation — Healthcare Technology](https://github.com/FrannyBrave/splunk-siem-hipaa-monitoring-case-study)
Deployed Splunk Enterprise SIEM for a 250-person healthcare technology organization. Built 10 custom SPL detection rules, automated HIPAA audit reporting, and executive security dashboards. Reduced Mean Time to Detect from 45+ days to under 15 minutes. HIPAA audit passed with zero findings.

> `Splunk` `SIEM` `HIPAA` `Detection Engineering` `Security Dashboards`

---

### 🏢 [SOC 2 Readiness & Security Policy Suite — SaaS Startup](https://github.com/FrannyBrave/soc2-readiness-security-policy-suite)
Full SOC 2 Type II readiness assessment for a Series A SaaS company. Assessed 47 controls, identified 23 gaps including 7 critical findings, and delivered a complete security policy suite (AUP, Password & Access Management, Incident Response, Data Classification, Remote Work) with a 90-day remediation roadmap.

> `SOC 2` `GRC` `Security Policies` `NIST` `Compliance Readiness`

---

### ⚖️ [Penetration Test & Vulnerability Assessment — Law Firm](https://github.com/FrannyBrave/law-firm-vulnerability-assessment-case-study)
Scoped external and internal penetration test and vulnerability assessment for a 38-person litigation firm. Identified 14 confirmed findings including 3 critical — unauthenticated RCE, Active Directory privilege escalation, and plaintext document transmission. Delivered executive summary, technical report, and vulnerability assessment with phased remediation roadmap.

> `Penetration Testing` `Vulnerability Assessment` `MITRE ATT&CK` `PTES` `Risk Reporting`
